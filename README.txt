WORKOUT APP — Personal Fitness Tracker
=======================================

WHAT THIS APP DOES:
The workout app lets me keep track of my exercises, number of reps, number of sets,
weights and variations. The idea is for me to see progress as I keep going to the gym
and do various exercises from weight lifting to cardio.

FEATURES (PLANNED):
- Log daily workouts (exercise name, sets, reps, weight, variations)
- Track both weight lifting and cardio exercises
- View workout history by date
- See progress over time (e.g. how much weight I've added, how reps have improved)
- Works on my phone

BUILT WITH:
- Claude Code (AI assistant)
- HTML, CSS, JavaScript (the building blocks of web apps)
- GitHub (for saving and publishing the app)
